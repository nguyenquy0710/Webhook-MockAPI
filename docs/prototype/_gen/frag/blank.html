Typography

System UI font stack (Bootstrap default), 16px base. Headings fw-bold or fw-light as in the screens; code and log text use monospace at 0.875rem.

Spacing, radius, shadow

Bootstrap spacing scale (mb-3 / p-4). Card radius 0.375rem, auth cards rounded-4, pills rounded-pill. Cards use shadow-sm; header uses shadow.

Controls

Inputs use form-control (38px), form-floating on auth screens (form-control-lg). Table row actions use icon buttons with tooltips.

Conventions

  • Language: English. Dates yyyy-MM-dd HH:mm:ss (UTC for logs). Status codes as badges.
  • Icons: Font Awesome 6.5.1. Destructive actions always ask for confirmation.
  • States: empty table shows a muted inbox icon with a hint; success and error use dismissible alerts or toasts.
  • Accessibility: labels on all fields, aria-label on icon-only buttons, tooltips via title.
  • Sample data: user demo, domain mock.example.test; no real data.
