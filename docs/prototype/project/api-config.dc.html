You can use these variables in your response body using {{variable}} syntax:

KeyDescription
statusHTTP status code (e.g. 200, 404)
methodHTTP method (GET, POST, etc.)
pathRequest URI path
remoteAddrClient IP address
remoteHostClient hostname
remotePortClient port
localAddrServer IP address
localNameServer hostname
localPortServer port
urlFull request URL
uriRequest URI
protocolHTTP protocol (e.g. HTTP/1.1)
schemeRequest scheme (http/https)
serverNameServer name
serverPortServer port
contextPathApp context path
servletPathServlet path
characterEncodingCharacter encoding (e.g. UTF-8)
contentTypeRequest Content-Type header
headersMap of HTTP headers
queryParamsMap of query string parameters
paramsMap of all parameters (form/query)
cookiesMap of cookie name/value pairs

Example usage:

{
  "method": "{{method}}",
  "client": "{{remoteAddr}}",
  "headers": {
    "host": "{{headers.host}}",
    "user-agent": "{{headers.user-agent}}"
  },
  "query": {
    "param1": "{{queryParams.param1}}",
    "param2": "{{queryParams.param2}}"
  }
}
